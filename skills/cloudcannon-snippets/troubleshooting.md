# Snippet troubleshooting

Symptom index. Each row names what you observe and points at the rule that owns the fix — the rules themselves live in [gotchas.md](gotchas.md), [raw.md](raw.md) and [snippets.md](snippets.md), and are not repeated here.

| Symptom                                                                          | Cause                                                                     | Fix lives in                                                                                                               |
| -------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| A snippet fires inside a fenced code block in a docs-style post                  | The parser does not know code blocks are inert                            | [gotchas.md § Snippets matching inside code blocks](gotchas.md#snippets-matching-inside-code-blocks)                       |
| `key_values` snippet round-trips wrongly, or values lose their quoting           | `root_value_delimiter` and `string_boundary` unset                        | [gotchas.md § Raw `key_values`](gotchas.md#raw-key_values-set-root_value_delimiter-and-string_boundary)                    |
| Config is rejected, or `key_values` behaves as if empty                          | The model was written as an object, not an array                          | [gotchas.md § `key_values` models must be an array](gotchas.md#key_values-models-must-be-an-array)                         |
| A component with children (e.g. `Tabs` > `Tab`) only ever parses the first child | Nested children need the `repeating` parser, not a flat one               | [gotchas.md § Nested component children](gotchas.md#nested-component-children-must-use-the-repeating-parser)               |
| Editing throws on save, complaining it cannot stringify                          | Round-trip safety rejects output it cannot re-parse                       | [gotchas.md § Round-trip safety](gotchas.md#round-trip-safety-throws-on-unparseable-stringify-output)                      |
| An HTML attribute value is mangled or dropped                                    | `argument` is the wrong parser for attribute values                       | [gotchas.md § Don't use `argument` for HTML attribute values](gotchas.md#dont-use-argument-for-html-attribute-values)      |
| Editors see raw `import` statements at the top of MDX content                    | Imports are not being injected at build time and stripped from source     | [astro/overview.md § Auto-import](astro/overview.md#auto-import-keeping-import-statements-out-of-content)                  |
| A custom snippet is ignored in favour of a built-in one                          | `_cc_` snippets are deprioritized during matching                         | [gotchas.md § `_cc_` snippets are deprioritized](gotchas.md#_cc_-snippets-are-deprioritized-in-matching)                   |
| A snippet matches content it should not, after enabling `_snippets_imports`      | `_snippets_imports` is too broad for migrations                           | [gotchas.md § `_snippets_imports` can match unintended content](gotchas.md#_snippets_imports-can-match-unintended-content) |
| The Content Editor toolbar shows "unconfigured snippets"                         | The markdown input has no explicit `options:`, or used plural `snippets:` | [cloudcannon-configuration/troubleshooting.md](../cloudcannon-configuration/troubleshooting.md)                            |
